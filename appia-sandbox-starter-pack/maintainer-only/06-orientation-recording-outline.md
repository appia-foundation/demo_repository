# Orientation recording outline (about 8 to 10 minutes)

Record your screen with any tool (Zoom, Loom, QuickTime) and share the link in the README and email. Use the sandbox itself and a non-admin account, so people see what they will see.

| Time | Segment | What to show |
|------|---------|--------------|
| 0:00 | **Why we're here** | One slide or sentence: the membership agreed to host specifications on GitHub. This is a practice space. |
| 0:45 | **Tour of the repo** | The file list, README, the tabs (Issues, Pull requests, Discussions, Actions), and the folder map in the README. |
| 2:00 | **Raise an issue** | New issue → *Propose a change* template → fill it in → submit. |
| 3:30 | **Branch and edit** | Create a branch, open the sample spec, edit a line, commit with a clear message. |
| 5:00 | **Open a pull request** | Fill in the template, link the issue with `Closes #`, request a reviewer. |
| 6:30 | **Review a pull request** | Files changed → comment on a line → suggested change → approve. |
| 7:45 | **Merge and see the result** | Merge, show the issue closing automatically, show the history/blame view. |
| 8:45 | **Where to get help** | FAQ, glossary, Discussions, contact. Point to the first exercise. |

## Tips

- Keep it to one take per segment, and don't worry about small slips. It shows people that mistakes are fine.
- Zoom in on the browser so text is readable on a phone.
- Add captions or a transcript if you can.
- Avoid showing any real member email addresses or private repositories.
