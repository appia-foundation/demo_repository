# Security

This is a practice repository. It contains no software, credentials or real specification content, so there is nothing here to attack.

If you notice something that looks sensitive (for example, someone has pasted a password, a private document or personal data), please do **not** comment on it publicly. Contact the repository administrator, Sean Mcilroy (`@seanmcilroy29` on GitHub), directly, and he will remove it.

Please never add confidential or sensitive information to this repository: it is public.
